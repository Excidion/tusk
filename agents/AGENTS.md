# Project instructions

## Plans and specs
Superpowers plans and specs live at the repository root:

- plans: `agents/superpowers/plans/YYYY-MM-DD-<feature-name>.md`
- specs: `agents/superpowers/specs/YYYY-MM-DD-<topic>-design.md`

They must stay out of `docs/`, because zensical builds every markdown file under
`docs/` into the published site and offers no way to exclude a folder.
